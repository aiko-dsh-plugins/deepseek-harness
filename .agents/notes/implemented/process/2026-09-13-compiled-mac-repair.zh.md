# Agent Note：Mac 修复制品的原生验证

Status: implemented

[English](2026-09-13-compiled-mac-repair.md) | 中文

## 问题

Apple Silicon 桌面安装器需要迁移已退役的插件制品 URL。现有 Mac 发行版已经包含验证过的运行时和核心包；本次修复更改桌面外壳和预装市场。

## 决策

手动选择的修复分支在公开分发仓库中运行有时限的原生 Mac 作业。作业从发行版下载现有安装包，并从所选修复分支读取摘要固定的已编译修复归档，更新外壳与 npm seed、刷新 ASAR 完整性，并对内测应用进行 ad hoc 签名。它检查离线首次启动、原生编辑、staging 失败后的保留行为以及启动迁移，然后上传可审阅的制品。私有源码仓库和凭据不是构建输入。作业仅有仓库只读权限，不能发布发行版。

## 影响

检查原生证据后，发行版仍通过单独步骤发布。修复保留应用现有数据目录，仍未经过公证，并禁用自动更新。已编译内容改变时，修复归档摘要必须同步改变。
